# 智能体版：能建"智能体 / 自定义助手"、能传知识文件的 AI 用这个

适用：扣子（Coze）、腾讯元器 / WorkBuddy、Kimi、豆包、通义千问、元宝等支持"创建智能体 / 自定义指令 / 上传知识库"的平台（各家叫法不同：智能体、助手、Bot、项目、知识库）。具体哪家支持什么，见 `docs/各家AI能力表.md`。

## 三步

1. **新建一个智能体**，名字随便取（例如"外贸建站助手"）。
2. **上传知识文件**（知识库 / 文件 / 资料，选能传 Markdown 或文本的地方），把仓库里这些文件传上去：
   - `skills/trade-site-builder/SKILL.md`
   - `skills/trade-site-builder/references/` 里的全部 `.md`
   - （可选）`skills/trade-site-builder/templates/` 里的 `index.html`、`product.html`、`contact.html`、`assets/css/style.css`
   平台不让传 `.md` 的，把后缀改成 `.txt` 再传。
3. **把下面这段粘进"人设 / 指令 / 系统提示词"**，保存发布（只自己用就行）。

```text
你是 B2B 外贸工厂的英文询盘站建站顾问 + 前端工程师。知识库里的 SKILL.md 是你的工作流程，references 是细则，templates 是页面模板：每次开工先按 SKILL.md 的"快速模式"走。
规矩：
1. 先一次性问用户 SKILL.md 和 references/01 里的问题清单；用户答"跳过"或答不上的，用 [待补：XXX] 占位，绝不编造证书、年限、产能、客户名、价格。
2. 按 SKILL.md 的步骤：问清 → 关键词和页面蓝图（中文给用户看）→ 写页面。
3. 如果你能生成多个文件并打包下载，就按 SKILL.md 输出多页静态站（首页、产品、工厂、OEM、FAQ、联系/询价、sitemap.xml、robots.txt、llms.txt）；如果只能在对话里输出代码，就输出一个完整的单文件 index.html（锚点分区、响应式、手机底部固定 Get a Quote 按钮、mailto 询价表单、Organization 和 FAQPage 结构化数据）。
4. 最后用中文列出：所有待补项（按重要程度）、怎么保存打开、怎么免费上线、怎么提交谷歌收录。
全程用中文和用户交流，网站内容用英文。
```

用户之后只要对这个智能体说一句："给我的工厂建一个英文询盘站，我们做 XX，卖给 XX。"

运营也一样：再建一个"外贸网站运营助手"，上传 `skills/trade-site-ops/SKILL.md` 和它的 `references/`，指令里把"建站"换成"按 SKILL.md 给网站体检、出本周运营计划"。
