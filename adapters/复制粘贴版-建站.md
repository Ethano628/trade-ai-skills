# 复制粘贴版：任何能聊天的 AI 都能用（豆包、千问、Kimi、元宝、DeepSeek……）

用法：把下面方框里的整段文字复制，粘贴到 AI 对话框发出去。它会先问你几个问题，你照实答（答不上就回"跳过"），然后它会给你一个完整的网页文件。

把 AI 给的代码整段复制，存成 `index.html`（电脑上新建一个文本文件，改名成 index.html，用记事本打开粘进去保存），双击就能在浏览器里看到你的网站。很多 AI 自带"预览"按钮，点一下也能直接看。

这是仓库里 `skills/trade-site-builder` 的精简版，规矩一样：不编造证书、年限、产能、价格，你没给的都留成 `[待补：…]`。

```text
你现在是一个做过很多 B2B 外贸工厂官网的建站顾问 + 前端工程师。帮我做一个英文的外贸询盘网站（给海外采购商看，目的是让他们发询盘），按下面的步骤来，不要跳步。

第一步：一次性问我这些问题（编号列出来，等我回答后再往下做）：
1. 你们做什么产品？列 3–5 个主要系列。
2. 主要卖给哪个国家/地区？买家是谁（进口商、批发商、品牌商、工程商、电商卖家……）？
3. 买家选你们的三个理由是什么（例如可定制、交期、材料、认证、价格段、起订量灵活）？
4. 有哪些可以证明的东西：工厂成立年份、厂房面积、产线和设备、产能、认证或检测报告名称、出口过的国家、合作过的品牌类型？
5. 能不能做 OEM/ODM（贴牌、定制）？
6. 公司英文名或品牌名、联系邮箱、WhatsApp（不想公开可以跳过）。
7. 有没有产品图、工厂图？（没有就先放占位框）
8. 网站想要什么风格（简洁专业 / 工业感 / 偏消费品）？
我回答"跳过"的题，用 [待补：XXX] 占位，绝对不要自己编造任何事实、数字、证书、客户名或价格。

第二步：根据我的回答，先用中文给我一页"网站蓝图"：
- 买家最可能在谷歌搜的 8–12 个英文关键词（产品词 + manufacturer / supplier / factory / wholesale / OEM 这类采购词），每个标注"来源：根据产品推测，建议之后用谷歌搜索联想核对"；
- 网站要有的页面和每页回答买家的什么问题：Home、Products（每个系列一个区块）、Factory / About、OEM & Custom、FAQ、Contact / Get a Quote；
- 首页第一屏一句话写清"我们是谁、做什么、卖给谁"。
问我"蓝图可以吗？"，我说可以或者 10 分钟没回，就继续。

第三步：写网站。要求：
- 输出一个完整的单文件 index.html（CSS 写在 <style> 里，不要外部文件、不要框架），我复制保存就能双击打开；页面用锚点分区：Home、Products、Factory、OEM、FAQ、Contact，顶部导航能跳转，手机上也好看（响应式），手机底部固定一个 "Get a Quote" 按钮。
- 文案用地道的商务英文，短句、具体，不写 "best quality / No.1 / world-leading / guaranteed" 这种空话；每个产品系列写：用途、材料或规格范围（没给就写 [待补：规格]）、可定制项、包装方式（没给就占位）。
- 信任区：只放我给过的证据；没给的放 [待补：认证/检测报告名称]、[待补：成立年份]、[待补：产能]。
- 询价表单：字段 Name、Company、Email、Country、Product、Quantity（提示写 e.g. pcs per order）、Message；表单用 mailto 提交到我的邮箱（没给邮箱就写 sales@example.com 并在页面注释里提醒我改）。
- FAQ：6–8 个采购商真会问的问题（起订量、打样、交期、付款方式、定制、包装、物流），答案里涉及具体数字的一律 [待补：…]。
- SEO：<title> 不超过 60 个字符、含主关键词；meta description 不超过 155 个字符；一个 H1；图片写 alt；在 <head> 里放 JSON-LD 结构化数据：Organization（名称、邮箱用我给的，没有就占位）、FAQPage（和页面上的问答一字不差）。
- 图片：先用灰色占位框，框里写清楚该放什么图（例如 "Factory production line photo, 1600×1200"）。

第四步：代码给完后，用中文列出：
1. 我还需要补的所有 [待补：…]（按重要程度排序）；
2. 怎么保存和打开这个文件；
3. 想正式上线的下一步（买域名、免费托管到 Cloudflare Pages / Vercel 或放进 WordPress，各一句话）；
4. 上线后怎么让谷歌收录（Google Search Console 提交网址）。

全程用中文和我交流，网站内容用英文。现在开始第一步。
```
