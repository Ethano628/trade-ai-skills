# 设计：参考站 → 视觉规则 → 三个样板

**不同产品不该长一个样。** 模板只是骨架；每个站按自己买家的决定和自己选的参考站来设计。

## G1 参考站
- 来源：采购词谷歌前 10 名里做得好的、同品类国际品牌站、用户喜欢的站。
- 选 1 个**主视觉标准站**（视觉质量最高、买家最像）+ 2–3 个补充参考站（各借一块：产品选择器、规格表、定制流程、工厂展示）。
- 只借布局、尺度和信息层级。**不抄文字，不用它们的图片和 Logo。**
- 写进 `project/04-design-rules.md`，每站五项：链接、查看日期、可借鉴模块、不能照搬的边界、对应本站哪页。

## G2 视觉审阅
每个参考站看桌面（约 1440px 宽）和手机（约 390px 宽）：首屏、产品列表、产品详情、页尾。能用浏览器工具就截图存 `project/design-refs/`。回答四问：
1. 产品图够不够大、够不够真？
2. 是全宽大图的工业感，还是小卡片堆砌？
3. CTA 清楚但不过度吗？
4. 手机首屏还有没有有用信息？

## G3 本站视觉规则（8 项，每项要数值或具体做法）

| 项 | 要写什么 | 示例（虚构产品：不锈钢厨房挂架） |
|---|---|---|
| 1 气质 | 3–5 个形容词 + 禁用风格 | 干净、金属感、专业、可信；禁用：卡通、霓虹渐变、过度阴影 |
| 2 布局尺度 | 内容最大宽度、栅格、留白 | max-width 1200px；12 栏；区块上下间距 96px（手机 56px） |
| 3 首屏 | 结构、图片比例、文字量 | 左文右图 5:7；H1 ≤ 12 个词；1 主按钮 + 1 次按钮 |
| 4 字号层级 | 字体、H1/H2/正文字号、行高 | Inter / 系统字体；H1 48/56，H2 32/40，正文 17/28 |
| 5 色板和职责 | 每个颜色干什么 | 深墨 #1d2433 文字；钢灰 #5b6472 次级；品牌色 #0f6b5c 只给 CTA 和链接；背景 #f6f7f8 |
| 6 图片语言 | 风格 + 每页图片清单（来源：实拍 / 已有 / 待拍 / AI 示意） | 白底产品图 + 真实厨房场景；首页 6 张：… |
| 7 组件和动效 | 卡片、表格、按钮、动效限度 | 圆角 6px；表格斑马纹；悬停只做轻微位移，不做大动画 |
| 8 手机端 | 390px 下的做法 | 导航折叠；首屏图在文字下方；规格表横向滚动；询价按钮常驻底部 |

最后写一句话方向：
> 以 <主标准站> 的 <某方面> 为质量基准；首页首屏采用 <做法>；产品页采用 <做法>；CTA 只用 <颜色/形式>；不使用 <禁用项>。

## G4 三个样板 + 并排验收
- 做首页、产品中心、一个主力产品页（高保真，真图或明确标注的占位框）。
- 和主标准站在桌面、手机两种宽度并排比：首屏视觉权重、内容宽度、图片尺寸和裁切、字体层级、CTA 对比、模块节奏、页尾、手机完成度。差的当场改。
- 比较结论写进 `04-design-rules.md`，再请用户看方向。

## 图片规矩
- 主图用真实产品照或工厂照。没有实拍时可以用 AI 生成的产品/场景示意图，alt 里写 "Illustration"，不改变产品真实结构，图上不出现编造的文字或认证标志。
- 两样都没有：放**明确标注的占位框**（如灰底写 "Product photo: roll up table, white background, 1600×1200"），上线前必须替换。模板里的 `.ph` 灰色斜纹框就是这种占位框，可以直接用——它明确写着缺什么图，不算"花纹冒充产品"；不能用的是不写字的装饰花纹、无关图库图。
- 每个产品页主图不同；文件名描述性英文；导出 WebP/JPG，宽 1600px 以内，写 width/height 防跳动。
