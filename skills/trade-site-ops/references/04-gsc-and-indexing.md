# 测量基线、收录和 Google Search Console 读数

## 一、测量基线（F1，`ops/baseline.md`）

| 指标 | 第 0 周 | 数据来源 | 备注 |
|---|---|---|---|
| 有效自然询盘（本月） | | 询盘邮箱/表单记录 + "How did you find us" | 北极星 |
| 已收录的商业页数 / 商业页总数 | | GSC 网页编制索引报告 / 网址检查 | |
| 前 20 名的商业意图词数 | | GSC 查询报告（平均排名 ≤ 20，业务价值 ≥ 2） | |
| 28 天展示 / 点击 / 平均 CTR | | GSC 效果报告 | |
| AI 答案提到我们的比例 | | `geo-log.md` 固定问题集 | |

| Bing 已编入索引网址数 | | Bing Webmaster | |

没接的写"未接入"，并把接入排进本周计划。

## 二、接入（用户本人操作，AI 给步骤）
- **GSC**：添加网域资源（DNS TXT 验证）→ 提交 `https://域名/sitemap.xml`。
- **Bing Webmaster**：从 GSC 导入 → 提交 sitemap。ChatGPT 搜索等会用到 Bing 索引。
- **IndexNow（可选）**：在网站根目录放钥匙文件，新页/改页时推送给 Bing 等支持的引擎。
- **数据给 AI**：GSC 效果报告 → 选近 28 天 / 近 3 个月 → 导出 CSV（查询、网页两张）放 `ops/data/`。每周一导一次。

## 三、收录排查（"为什么没收录"）

先用 GSC 网址检查工具查具体页，按状态处理：

| GSC 状态 | 常见原因 | 动作 |
|---|---|---|
| 已发现 - 尚未编入索引 | 站新、权重低、抓取预算、内链少 | 加内链（从首页/产品中心链过去）、进 sitemap、请求编入索引；耐心等 2–4 周 |
| 已抓取 - 尚未编入索引 | 质量或重复：内容薄、和别的页太像 | 补原创内容和证据，或合并到强页；不要反复请求 |
| 网页会自动重定向 / 备用网页（有规范标记） | 正常，或 canonical 设置问题 | 核对 canonical 是否指向想要的网址 |
| 已被 robots.txt 屏蔽 / 已排除（noindex） | 误设置 | 去掉屏蔽或 noindex（如果这页该收录） |
| 重复网页，Google 选择的规范网页与用户指定的不同 | 内容重复、内链指向不一致 | 统一内链和 canonical，合并重复页 |
| 未找到（404）/ 软 404 | 删页没跳转、页面太空 | 301 到最相关页，或补内容 |

新站上线头 1–2 个月收录慢是常见现象。先保证：sitemap 成功、重要页内链充足、没有技术屏蔽、内容不是近似页。

## 四、每周怎么读 GSC（10 分钟）
1. **效果 → 查询**：按展示排序。
   - 排 4–20 名、展示多的 → 快赢改写候选。
   - 新出现的词 → 加进关键词宇宙。
   - 展示多但 CTR 很低 → 改 title/description。
   - 同一个词两个网址交替出现 → 自相残杀，合并。
2. **效果 → 网页**：哪些页开始有展示、哪些掉了。
3. **编制索引 → 网页**：未编入索引的数量和原因变化。
4. **体验 / 增强功能**：结构化数据报错（面包屑、FAQ、产品）。
5. 写进周报数据段：和上周比的变化，不写小数点级波动。

## 五、读数的规矩
- 看趋势不看单日；新页至少等 2–4 周再判断。
- 一次只改一个变量，改动日期记在周报，才能归因。
- 询盘归因：表单 "How did you find us" + 分析工具来源（可选）+ 询盘人提到的搜索词。
