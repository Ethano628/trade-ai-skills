# 周计划、周报、月报模板

原则：只写结论和动作；每个动作写"看哪个数、什么时候看"；要用户本人做的单独列在最前面。

## 一、周计划 `ops/week-YYYY-Www-plan.md`（周一）

```markdown
# 第 YYYY-Www 周计划 — <站点>
> 日期：YYYY-MM-DD · 阶段：地基 / 冲刺 · 上周复盘：week-…-review.md

## 要你本人做的（共 N 件，预计 X 分钟）
1. 导出 GSC 近 28 天查询和网页 CSV，放 ops/data/（5 分钟）
2. 提供证据：工厂面积、样品交期（补事实卡 F02、O03）
3. 用你的 LinkedIn 账号发外链卡第 1 条（稿件在 backlinks.md）

## 本周动作
| # | 类型 | 动作 | 依据（六列/体检编号） | 谁做 | 产出 | 过关标准 | 看哪个数、何时看 |
|---|---|---|---|---|---|---|---|
| 1 | 技术修复 | 去掉 /products/ 下误加的 noindex | 体检 P0-2 | AI | 改动文件列表 | 页面源码无 noindex | GSC 编入索引数，2 周后 |
| 2 | 改写 | /products/wall-rack.html 对准 "304 stainless wall rack supplier" | GSC 排 14，28 天展示 … | AI 起稿 | 新稿 | 过发布前检查 | 该页排名/CTR，3 周后 |
| 3 | 新页 | … | 选题六列齐 | AI 起稿 | … | … | … |
| 4 | 外链 | … | 外链清单第 n 条 | 用户发 | … | … | 30 天后复查在线 |
| 5 | GEO | 补 FAQ "typical MOQ for OEM kitchen racks" | geo-log 未提到 | AI | … | … | 下周抽查 |

## 本周不做（及原因）
- …
```

## 三、月报（每月第一个工作日）

```markdown
# YYYY-MM 月报 — <站点>
1. 北极星：有效自然询盘 N 个（来源分布：Google n / AI n / 站外 n / 其他 n）
2. 先导指标趋势（4 周）
3. 本月做了什么：新页 n、改写 n、外链 n（成功 n）、技术修复 n
4. 哪些有效、哪些没效（每条带数据和改动日期）
5. 下月计划和要用户本人做的事
```

## 四、季度策略（每季度）
主题地图增删、竞品集重看、外链差距再做一轮、下季度北极星目标和先导指标目标。

## 写作规矩
- 不写小数点级波动，不堆图表。
- 没效果就写没效果和推测原因，不粉饰。
- 不承诺排名和询盘数字。
