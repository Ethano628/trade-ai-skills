# 询盘转化检查

流量来了不发询盘，问题通常在这里。每月查一次，改版后必查。

## 一、询盘链路（P0）
- [ ] 真实提交一次表单：邮件到了、内容完整、"回复"能直接回到询盘人邮箱
- [ ] 用户常用邮箱/手机有通知；不进垃圾箱（企业邮箱配好 SPF/DKIM/DMARC）
- [ ] 表单服务额度没用完、没过期
- [ ] mailto 方案：页面有明文邮箱作后备（很多访客没有本地邮件客户端）
- [ ] WhatsApp 链接能打开且号码有人看
- [ ] 每个询盘有记录（表格即可：日期、国家、公司、产品、数量、来源、是否有效、后续）

## 二、每个商业页
- [ ] 首屏有 CTA，手机端底部常驻 CTA
- [ ] CTA 用具体动作："Get a Quote"、"Request Samples"、"Send Your Drawing"
- [ ] 产品页的询价按钮带产品名预填
- [ ] 回复时效写明（且做得到）
- [ ] 条款块（MOQ、样品、交期、付款、港口）可见——采购商不想为基本信息发邮件
- [ ] 信任证据靠近 CTA：工厂实拍、证书、质检流程、真实联系人

## 三、表单本身
- [ ] 字段不多不少：姓名、公司、邮箱、国家、产品、数量、留言、How did you find us?
- [ ] 必填只放真正必要的；错误提示清楚
- [ ] 手机上好填（输入类型正确：email、tel）
- [ ] 有防垃圾（蜜罐字段或表单服务自带过滤），但别加难用的验证码

## 四、有效询盘的判断
有效：真实公司或个人、写了具体产品/数量/用途、留了能回复的联系方式。无效：推销、SEO 服务、明显机器人、学生作业。周报里只算有效询盘。

## 五、看数
- 商业页访问 → 询盘的比例（有分析工具时）
- 询盘来源分布（"How did you find us"）
- 询盘里反复问的问题 → 补进 FAQ 和关键词宇宙（业务价值 3）
