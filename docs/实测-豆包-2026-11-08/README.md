# 实测：豆包网页版 + 复制粘贴版（2026-11-08）

- 工具：豆包网页版（doubao.com），**没登录**，免费。
- 做法：把 `adapters/复制粘贴版-建站.md` 方框里的整段粘进去 → 它一次问 8 个问题 → 用虚构品牌"Northbay Drinkware"（不锈钢保温杯，卖美国和欧洲）回答，证据类问题全部"跳过" → 它出中文蓝图 → 给出完整单文件 `index.html` → 列待补清单、保存方法、上线和谷歌收录步骤。
- 结果：`index.html`（本目录，原样保存，未改）双击可开；英文首页、4 个产品区、About、OEM、FAQ、询价表单（mailto）、手机底部固定"Get a Quote"；title 含主词；2 段 JSON-LD（Organization、FAQPage）；23 处 `[待补：…]`，没有编造证书、年份、产能、价格。
